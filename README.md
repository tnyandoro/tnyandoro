## 🚀 Featured Projects

### 🌾 AgriLink – Agricultural Marketplace Platform
A digital platform connecting **farmers, transporters, and buyers** to improve agricultural trade and logistics.

**Tech Stack**

React | Ruby on Rails | PostgreSQL | Leaflet | Supabase | Render | Vercel

**Key Features**

- Farmer produce listings  
- Transport logistics coordination  
- Interactive geospatial map of farms and deliveries  
- Admin monitoring dashboard  
- Ratings and dispute resolution system  

**Engineering Decision**

Originally planned to use Google Maps, but redesigned the mapping layer using **Leaflet + OpenStreetMap** to reduce API costs while maintaining scalable geospatial visualization.
